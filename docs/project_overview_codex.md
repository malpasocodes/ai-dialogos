# Project Overview — AI-Innov Companion Site

**Title:** Artificial Intelligence: Shaping the Future of Innovation  
**Publisher:** De Gruyter (2025)  
**Goal:** Create AI-Innov, an interactive, educator-friendly companion site for the book.

---

## Project Summary
The site connects three key pillars:
1. **Book Website** – Core hub for resources, educator materials, and media.  
2. **Substack** – Essays and ongoing reflections tied to book themes.  
3. **Podcast** – Expert conversations expanding on book chapters.

Visitors should move fluidly between these elements through consistent AI-Innov design and navigation.

---

## 10-Phase Project Plan

| Phase | Focus | Key Deliverables |
|-------|--------|------------------|
| 1 | Discovery & Visual Direction | IA, wireframes, style board |
| 2 | High-Fidelity Design | Polished UI mockups, component library |
| 3 | Content Modeling | Astro collections, taxonomy, metadata schema |
| 4 | Technical Setup | Repo, CI/CD, hosting, skeleton pages |
| 5 | Component Development | Header, footer, hero, grids, search UI |
| 6 | Content Integration | Real content, Substack, podcast feeds |
| 7 | Gated Tools (Optional) | Supabase/Clerk setup for educators |
| 8 | QA & Accessibility | Testing, audits, optimization |
| 9 | Launch Prep | Content freeze, SEO, press kit |
| 10 | Growth & Optimization | Analytics, new modules, iteration |

---

## Technology Stack
- **Framework:** Astro + Tailwind + shadcn/ui  
- **Hosting:** Vercel or Netlify  
- **Search:** Pagefind  
- **Auth (optional):** Supabase or Clerk  
- **Integration:** Substack embeds, Podcast RSS feed  
- **Analytics:** Plausible or GA4
