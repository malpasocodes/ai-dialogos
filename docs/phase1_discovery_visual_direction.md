# Phase 1: Discovery & Visual Direction
*(AI-Innov companion site for “Artificial Intelligence: Shaping the Future of Innovation” — De Gruyter, 2025)*

## 1. Objective
Establish clear structure, visuals, and tone for AI-Innov before development begins. This phase defines the visual identity and site blueprint.

## 2. Deliverables
- **Information Architecture (IA):** Complete sitemap and page hierarchy.
- **Wireframes:** Low-fidelity sketches for top-level and key subpages.
- **Visual Direction Board:** Early color, typography, and style cues.
- **UX Flows:** Basic navigation and content interaction flow.
- **Phase Sign-off:** Approved wireframes and style direction prior to prototype build.

## 3. Page Inventory
### Top-Level Pages
1. **Home** — Hero, book summary, Substack + podcast highlights, educator resources preview.
2. **Book** — Overview, TOC, sample chapter, buy links.
3. **Educators Hub** — Lesson plans, slides, and teaching resources.
4. **Resources** — Code, datasets, frameworks, and slides.
5. **Podcast** — Episode list, embedded players, and show notes.
6. **Substack** — Embedded Substack feed.
7. **Events** — Speaking engagements and workshops.
8. **About** — Author bio, media kit, contact.

### Utility Pages
- 404, Privacy Policy, Accessibility Statement, Search Results.

## 4. User Flow Overview
**Primary audience journeys:**
1. *Educator Flow:* Home → Educator Hub → Download/Subscribe.
2. *Reader Flow:* Home → Book → Buy → Subscribe (Substack).
3. *Media Flow:* Home → About → Media Kit → Contact.

## 5. Wireframes to Produce
- Homepage (hero, 3 pillars, featured resources, Substack & podcast feeds).
- Educator Hub overview (card grid + filters).
- Resource detail page (downloadable content + tags).
- Book page (cover, summary, TOC, buy links).
- Podcast index (episode cards + embedded player).
- About page (bio, media links, contact form).

## 6. Visual Direction
Create a **style direction board** exploring:
- Typography (Inter, Source Sans, or similar).
- Color palette: neutral base + one vibrant accent.
- Layout rhythm: grid-based, airy spacing, large rounded corners.
- Iconography and imagery references (education, AI, innovation).

## 7. Tools & Outputs
- Wireframes: Figma or Excalidraw.
- Style Direction Board: Figma / Miro / PDF export.
- Deliverable: Phase 1 Package (`phase1-visuals.zip`) containing IA, wireframes, and board.

## 8. Timeline
Approx. **2 weeks**, including feedback and revisions.
